# 设备工作区布局（2026-11-02）

采用“设备列表直达”：桌面端和宽屏 Android 左侧直接显示远程设备，右侧承载概览、连接设置、全局设置和添加表单。添加入口位于设备列表标题旁，设置入口固定在列表下方。窄屏 Android 沿用列表／详情切换和设备、设置两个底部入口，添加操作归属设备列表。

- 设备列表与连接路径列表使用拖动柄，落点以插入线表示；原有 `device.move`、`settings.route.move` API 扩展目标与前后位置参数，兼容旧的 up/down 参数。Alt + 上下方向键及 Android 无障碍滚动动作提供键盘和读屏操作。
- 设备排序立即持久化，继续使用共享配置中的 devices 数组顺序进行 WebDAV 同步。拖动不切换当前设备，也不提交连接草稿。连接路径排序只修改当前设备的草稿，通过原有保存、取消流程处理。
- 全局设置和连接设置的 Tab 区域与内容之间保留固定分隔线、留白；正文滚动区域从分隔之后开始。主题切换集中于设置的外观分类。
- Android 完整悬浮键盘按可用宽度组织主键区、导航区和数字区；竖屏空间够时堆叠分区，窄屏逐行换行，空间不足时仅纵向滚动。保留 108 键、分区定位、修饰键状态及原有输入 API，按键不因屏幕变窄而缩小到不可点击。
- 历史版本采用整行展开控件，版本与发布时间分列；宽度不足时日期排在版本下方。历史正文继续使用 Markdown 渲染。
- 所有验证使用独立测试数据、原生控件测试与离屏绘制；不操作日常客户端、OPPO 或远程服务。
