## 实现修正

- Windows 侧栏导航补齐实际控件激活回调，鼠标、键盘、无障碍和测试接口使用同一导航函数，保留禁用、对话框及单次派发检查。
- 普通传输错误与草稿校验错误分开保留。HTTP 503 后切到关于、返回配置同步，错误仍显示；丢弃错误草稿会恢复原传输错误，成功重试或保存另一个账户后清除。
- Windows 与 Android 增加 `syncPasswordReusable` 状态。更改地址或用户名后，原账户密码不再显示“留空保留”，改为明确要求重新填写；密码输入框本身不重建。原有凭据保护规则保持：没有新密码时拒绝保存新的账户身份，不修改旧账户。

## HTTPS 与页面结果

端点为两套独立 localhost TLS 服务，使用虚构账户。受信根仅通过测试子进程的 SSL_CERT_FILE 提供，没有安装到 Windows 证书库，也没有跳过证书校验。

1. 不受信根证书被拒绝，服务端没有收到 HTTP 请求。
2. 更改服务地址而留空密码时拒绝保存；新草稿与旧账户分别保留，页面显示重新填密码的说明。
3. 补齐密码后真实 HTTPS GET / 条件 PUT 成功。
4. 使用 127.0.0.1 连接仅为 localhost 签发的证书时拒绝，未新增授权 HTTP 请求。
5. 错误虚构密码实际收到 HTTP 401，页面显示登录失败。
6. 服务 GET 返回 HTTP 503，错误在离开／返回页面后保留；解除故障后通过实际重试按钮完成同步。
