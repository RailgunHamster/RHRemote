深色轮还核对实际系统 IME 的显示／隐藏、继续会话、待退出取消，以及六组横竖屏和系统栏边距；转向由模拟器显示配置控制，不代表物理传感器、物理键盘或 OPPO 已验收。

浅色轮的受控故障产生替换 Game，恢复后的可见内容验证通过，观察到后继首帧 2783 ms，旧反馈清除。这是故障回调注入，`actualNetworkInterrupted=false`，不计作真实断网恢复。

UI 心跳采样分别记录 8／3／5 个迟到样本，最大观察延迟为 2069／1220／1755 ms；样本数不是独立卡顿次数。两轮栈包含 `RhHome.refreshDiagnosticBanner → RhShared.read/normalize`：隐藏状态栏也在读取和解析完整配置，应先移除这条多余路径，同时保留取消动作归属和显示时的新鲜别名。另有 Game 初始化键盘映射的 Binder 调用样本。采样不能证明全部首帧等待或全部 UI 延迟都由其中一项造成。
