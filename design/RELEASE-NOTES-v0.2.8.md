# RHRemote 0.2.8

本次更新 Android 客户端；Windows 客户端保持 0.2.7。

- 修复弱网下外网探测过早超时，以及旧串流窗口清理干扰新连接的问题。
- 打洞未得到直连时，按设备配置的优先级复用已经建立的公网中继；仍校验设备身份和配对证书。
- 网络短暂中断后，在有限时间内自动重试。可随时取消，不重复创建并行会话。
- 区分局域网与外网的首帧等待上限，取消启动请求时重试同一请求的清理确认。
- 更新页保留按钮和进度视图，立即显示检查、下载、校验及失败原因；下载并安装会打开 Android 系统安装界面，由用户确认。

保留已保存设备、各设备连接参数、配对和 WebDAV 配置。弱网仍可能卡顿或暂时不可达；本次没有承诺固定首帧耗时或稳定帧率。测试范围和逐帧证据见 `design/OPPO-WAN-VALIDATION-20261025.md`。
