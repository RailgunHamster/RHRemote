# RHRemote 0.2.24

## Windows 服务端单窗口远程修复

- 修复 OPPO 读取 RailgunHamster 窗口列表时等待 7 秒后报 timeout 的问题。窗口列表只枚举窗口信息，不再逐个创建捕获项；独立工作队列避免窗口枚举阻塞连接准备。
- 选定窗口后，由当前登录用户身份的受控子进程执行 Windows Graphics Capture，避开 SYSTEM 进程激活捕获项导致的 CaptureService RPC 失败。主服务继续保留原有的键鼠、锁屏和安全操作能力。
- 用户捕获进程与主服务通过私有继承句柄和共享 GPU 纹理交接画面，不增加网络端口，不经 CPU 复制整帧图像。校验原窗口身份，窗口缩放后重建捕获尺寸，窗口关闭后结束捕获，禁止退回桌面画面。

本机已通过真实 SYSTEM → 用户进程的测试窗口验证：首帧 274 毫秒，连续传帧、颜色校验、GPU 交接、缩放重建和关闭检查通过；36 项相关回归测试通过。这是捕获子流程耗时，不代表一次完整远程连接的首帧耗时。

Windows 服务端经已开启的自动更新安装，等待空闲并保留配置和配对。Windows、Android 客户端同步版本号与更新记录，无需重新配对；Android 沿用原签名，安装仍由用户手动确认。默认 CNB、GitHub 备用，不更新共享目录。Ubuntu 本轮保持 0.2.15。
