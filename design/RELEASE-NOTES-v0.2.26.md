# RHRemote 0.2.26

## Android

- 拖动悬浮键盘开关、手机键盘按钮、外层快捷键和简化键盘按键时，显示高对比度移动轨迹、起点虚线框和落点轮廓；白底和深色画面上都可见，松手后立即消失。
- 修复刷新控制状态时，正在拖动的按钮可能跳回原位的问题。
- 完整键盘模式也会记住两个外层键盘开关的位置。取消拖动、切换输入法、旋转屏幕或结束会话时清理拖动反馈，不误发快捷键。

已通过横竖屏和明暗背景的键盘渲染检查、18 项键盘回归测试，以及真实 Android 模拟器上的拖动、松手和取消检查。本轮未操作 OPPO。

Windows 同步版本号和更新记录。服务端沿用 0.2.25。更新默认 CNB，GitHub 备用；Android 沿用原签名，在系统安装界面由用户确认安装。
