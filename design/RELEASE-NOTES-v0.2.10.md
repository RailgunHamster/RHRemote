# RHRemote 0.2.10

Windows 和 Android 更新设备管理界面，沿用蓝紫配色。Windows 使用导航、可搜索设备列表和选中设备详情分栏；Android 在宽屏显示分栏，窄屏在设备列表与详情之间切换，支持横竖屏调整。

- 详情集中显示连接入口、当前客户端的画面与声音配置，以及设备排序操作；取消对特定主机名的固定高亮。
- Android 设置、同步和更新页的按钮组自动换行，统一间距和至少 48dp 的触控高度，处理系统栏与刘海区域的留白；深色模式同步系统栏背景与图标颜色。
- 设备选择与搜索使用共用动作接口；选择、搜索和刷新不会改写连接配置，也不会切换正在连接或串流中的目标。
- 保留各设备配置、别名、同步顺序和配对身份；Windows 继续使用 Velopack 更新，Android 仍由用户在系统安装界面确认。

Android versionCode 为 225，高于 0.2.10-preview.1 的 224，沿用已有签名，可覆盖升级，无需先卸载。Windows 提供安装版、便携版及自动更新包。

已完成 Windows 构建与交互回归、Android 188 项 JVM 回归和模拟器中的横竖屏、窄屏、130% 字体、深浅主题及各设置分类的控件边界检查。此轮是界面验收，未新增 OPPO 实机、外网串流或持续动态帧率验收；已有连接与性能待办继续保留。
