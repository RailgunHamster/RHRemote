# RHRemote Android 0.2.5

- 更新页主按钮改为“下载并安装”：发现新版本后可直接下载、校验并打开系统安装界面，显示下载进度及明确的失败原因。
- 缺少安装权限时打开 RHRemote 的对应系统设置；允许后返回应用继续安装。拒绝权限或取消安装后可以重试，后台自动下载不会自行打开安装器。
- 保存已下载安装包的记录，重新检查更新、旋转屏幕或重开应用后可继续安装；安装前重新核对完整文件哈希、包名、版本及签名。
- 初次连接显示选路、配对状态和应用读取阶段，可以取消。取消后等待真实清理完成，迟到的请求不能打开旧会话；连接任务使用独立工作线程。
- 包含 0.2.4 的 Tailscale 备用地址发现、配对持久化、VPN 发现竞争和更新页 `null` 修复。

本次为 Android 正式更新，versionCode 207，签名与 0.2.3 / 0.2.4 一致，可直接覆盖安装。
系统安装确认仍需手动完成，不需要卸载旧版，设备列表、配对和配置会保留。
旧版“安装更新”不会自动下载时，可以先点“下载 APK”，或在浏览器下载本次 APK 后打开安装。

Windows 仍为 0.2.3，其更新 feed 保持不变；本次不部署服务端。
自动化测试和构建不代替 OPPO 实机验收，升级后的外网视频及系统安装流程仍待现场确认。
