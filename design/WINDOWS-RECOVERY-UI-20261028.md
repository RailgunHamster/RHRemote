# Windows 恢复界面的连续性与失败操作

本地 Windows `0.2.11-preview.63` 修复串流进程交接期间悬浮控制条消失的问题。恢复提示、取消、失败后的重试与返回保留在原会话位置；本轮没有改变串流恢复次数、等待时间或编解码参数。Android 保持 `preview.57`，OPPO 未操作。完整 UI 目标仍未完成。

## 原因与修改

原控制条只依附当前原生串流窗口：窗口隐藏、销毁或暂时没有有效句柄时直接隐藏控制条。自动恢复会结束旧进程并创建新进程，因此连接正在恢复时反而没有原位取消入口。`preview.60` 实际复现约三秒空档。

现在按设备 UUID 与用户连接请求的 attempt 保存已验证的窗口位置。原生进程替换不改变该请求；窗口暂时隐藏、句柄失效或几何信息不可用时，控制条解除旧窗口的 owner，继续显示恢复状态和取消按钮。新窗口经过 PID、可见性和位置核对后重新附着。关闭／取消、离开连接页、换设备或无关请求会清除缓存；失败后对同一设备明确重试可以继承位置。

缓存位置使用原显示器信息校验，失效时隐藏，不另选显示器。窗口显示和换 owner 使用不激活方式，控制条保持工具窗口。当前原生窗口被最小化时仍隐藏控制条。恢复阶段禁用远程操作，保留取消；清理期间取消按钮禁用。终止失败使用独立错误卡片，提供顶部关闭、返回设备、重试和 Escape；不混用快捷键／屏幕操作的错误状态。正文按卡片宽度换行并独立滚动，底部按钮固定。

新增按钮复用已有共享动作 `connection.retry`、`connection.dismiss` 和 `navigation.back`。隔离 UI 测试接口只在当前 UI 所属 UUID、attempt 和可见失败卡片匹配时允许操作已脱离原生窗口的控制条，过期卡片不可操作。

## 证据与复验

证据根目录：`D:\RHRemoteTools\ui-recovery61-review-20261028`。Windows 使用实体 `DISPLAY2 / C3273IUY`、不激活窗口、关闭声音与物理输入；连接现有 winserver。中断通过已有 `stream.test.interrupt` 进入真实原生终止、清理与自动重连链路。它是受控传输终止，不能代替物理断网或 OPPO 外网验收。

- `baseline-result.json`、`baseline-observations.json`：不可变 `preview.60` 的控制条空档，随后实际自动恢复与取消。`baseline-cleanup.json` 确认清理完成。
- `fixed/`、`continuity-review62.json`：中间包 `preview.62` 的恢复、取消、失败操作与清理通过，但全量观察另发现 4 个隐藏样本，发生于两轮原生退出期间。原脚本仅对第一轮连续性断言，不能把其 `passed` 扩大解释为全部连续性通过。修正后脚本检查每一轮；历史脚本另存 `Verify-Recovery62.ps1`。
- `fixed2/result.json`、`fixed2/observations.json`：最终 `preview.63` 完整重跑，自动恢复、取消并完成清理、取消后观察四秒无重连、两次恢复达到上限、原位重试出画面，以及返回原设备／搜索条件均通过。
- `verification63.json`：恢复及失败窗口的 465 个观察点中隐藏为 0；包括 2 个原生窗口仍有句柄但已经隐藏的样本、400 个句柄缺失／失效样本，均保留控制条。观察为约 60–100 毫秒轮询与 UI 状态证据，不是逐显示帧或物理呈现保证。
- 最终流程执行 3 次主界面实际按钮、3 次悬浮实际按钮及失败卡片 6 步双向 Tab。每次控件记录核对副屏及 `windowActive=false`；没有 OS 输入注入或系统截图。
- 最终 10 个原生会话均有实际解码与 `render_return` 事件，尾部 `trace_end` 完整、丢失事件为 0。原始原生记录合计 282,036 字节，为本次恢复证据保留，不将短静态会话解释为持续帧率验收。
- `regression63.log`：170 项 UI 回归通过，包括真实 Slint 控件、失败卡片的浅深主题、355／560 逻辑宽度、1／1.5／2.25 缩放、长错误滚动与底部按钮、键盘及过期卡片拒绝。

长错误渲染图在 `layout-corrected/`；真实恢复图在 `fixed2/recovery-pending.png`、`fixed2/recovery-failed.png`。最初测试后端按 scale=1 分配截图缓冲，不能用其高缩放图片作为通过证据；新测试分别设置物理缓冲和逻辑 resize，并断言图片实际尺寸。正文直接放入滚动区也曾未形成正确高度，已改为垂直布局并断言能够滚动且按钮位置不动。早期失败日志及图片保留。`preview.61` 是修正正文前的内部包，未用于最终验收或交付；旧包均未覆盖。
