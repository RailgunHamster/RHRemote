# RHRemote 0.2.11

## 新功能

- Android 控制页新增“点击与滚动”：轻点仍是主键点击，单指横纵滑动发送滚轮，双指平行滑动拖动，双指捏合保留缩放。尊重交换左右键和反向滚动设置；该模式只作用于当前会话，与其他触控模式互斥。
- Windows 和 Android 的设备页新增“选择窗口”。服务端通过 Windows Graphics Capture 捕获所选窗口，客户端按窗口比例限制输出大小；临时窗口标识不进入配置同步。

## 修复

- 已显示远程画面的会话正常结束时显示“已断开”，不再误报“连接失败 / 远程连接已结束”。首帧前异常结束、明确错误及意外断线恢复仍分别处理。
- 窗口串流的重试保留原目标，目标失效时明确失败，不回退到整个桌面。读取窗口列表结束后立即释放准备资源，避免等待不存在的串流交接。

## 窗口串流的预览范围

窗口串流需要本版 RHRemote-Sunshine 服务端。旧服务端仍可使用桌面连接；客户端不会代为安装或重启服务。

这不是独立 Windows 登录会话。窗口仍属于被控电脑当前桌面，首次输入前可能需要轻点激活；最小化、关闭或权限变化会使捕获停止。独立弹窗需要另选目标，系统界面和安全桌面请用桌面连接。音频仍使用现有系统音频开关，不按进程隔离。窗口模式支持键鼠和客户端触控转鼠标，暂不转发原生触笔和手柄。

已完成协议、目标归属、捕获生命周期、坐标映射的编译与自动测试，以及专用 Android 模拟器中的真实 View 手势测试。真实窗口画面、实体键鼠输入、同内容带宽对照仍待实机验收；不承诺固定流量节省比例。

## UI 和升级

设备列表与详情、设备内连接设置、分类设置、WebDAV、单按钮更新、顶部控制条及悬浮按键已经实现。整体 UI 改版尚未最终验收；OPPO 横竖屏、Windows 物理副屏及跨端同步与切网的联合验收仍待完成。

Android 保持原应用包名和签名，versionCode 为 415，安装仍由用户在系统界面确认。发布安装包不等于升级现有三台服务端，也没有操作 OPPO。
