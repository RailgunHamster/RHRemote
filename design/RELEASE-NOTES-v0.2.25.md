# RHRemote 0.2.25

## 服务端自动更新可靠性

- 更新日志和安装文件在 Windows 上遭遇短暂的访问拒绝、共享冲突或文件锁时，原子替换最多重试 5 秒；成功操作不增加等待。超时仍保留旧文件并执行原有回滚流程，不修改文件权限。
- 替换失败时记录具体目标路径，便于区分安装文件、备份和事务日志的错误。
- 已通过真实文件锁测试：读者释放文件后完成替换，持续占用时按时返回错误并保留源文件和目标文件；回滚与配对保留测试通过。

## 单窗口远程

包含 0.2.24 的 Windows 单窗口捕获修复。本机 RailgunHamster 升级后，OPPO 0.2.23 点击“重新读取”已正常显示窗口选择列表，服务端枚举约 11 毫秒，不再等待 7 秒后超时；无需重新配对。此次实机复验未启动串流。

捕获引擎沿用已验证的 0.2.24 构建。本机真实 SYSTEM → 用户进程测试窗口首帧 274 毫秒，传帧、颜色校验、GPU 交接、缩放重建和关闭检查通过；该时间只代表捕获子流程。

Windows 服务端自动更新等待空闲安装，保留配置和配对。Windows、Android 客户端同步版本号与更新记录；Android 沿用原签名，由用户手动确认安装。默认 CNB、GitHub 备用，不更新共享目录。Ubuntu 本轮保持 0.2.15。
