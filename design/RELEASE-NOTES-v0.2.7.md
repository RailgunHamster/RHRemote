# RHRemote 0.2.7

Windows 和 Android 客户端均更新到 0.2.7，Android versionCode 为 209，签名与旧版一致。两端使用 Release 构建，Android APK 不启用 debuggable。

- Windows 支持按设备设置多地址和连接路径顺序，使用局域网、Tailscale、内置直连或独立 HTTPS 中继；媒体失败按配置回退，保留配对证书校验。
- Windows 连接取消、后台启动交接和关闭窗口会等待本次原生进程实际清理；UI 意外退出时，独立通道进程保留中继直到原生清理结束。
- Windows 主界面和悬浮控制栏默认使用软件绘制，避开此前崩溃栈中的 WGL 呈现路径；视频仍由独立原生进程处理，硬件解码设置保留。
- 悬浮栏展开和收起使用同一位置的开关，透明区域不挡画面和点击；快捷键和选屏菜单可以滚动。
- Android 为每次实际启动请求分配独立取消凭据，使用单独的配对 TLS 请求完成清理；启动、取消及重连的占用保持到对应任务结束。
- 保留 Android 的“下载并安装”、下载进度、缓存校验和安装权限返回后的继续安装。系统安装仍需用户确认。
- Windows 设备页、关于页和更新状态使用实际构建版本，安装版本另在控制接口中报告。

按次启动取消需要主机声明 RHLaunchCancel 能力。旧 Sunshine 仍可连接，但无法获得新增的按次槽位取消；客户端更新不会自动替换现有主机服务。

Windows 已通过局域网及独立 HTTPS 中继的实际画面、取消、重连、窗口关闭和模拟 UI 退出验证。软件绘制的页面及悬浮栏短轮次验证通过；此前长期呈现崩溃的驱动根因仍未证明。Android 自动化及构建结果不等同于 OPPO 实机验收。蜂窝网络、系统网络切换及持续 30/60 FPS、4K 仍需继续验证。
