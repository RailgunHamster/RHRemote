# RHRemote 0.2.23

## RHRemote-Sunshine 自动更新

- Windows 服务端支持自动检查、下载和安装正式版，默认 CNB，失败时尝试 GitHub。可在服务端网页首页开关自动更新、调整来源及检查间隔，也可通过对应管理接口操作。
- 检查更新和下载在后台执行。安装等待远程会话、待处理连接及最近连接握手结束，再短暂阻止新连接进入；不会为更新中断正在使用的远程桌面。
- 更新清单使用独立 RSA 签名，安装包和包内文件逐一校验。服务重启由安装目录外的独立更新进程管理，带事务记录、健康检查及失败回滚。配置、证书、配对和自定义应用保留。
- 每次发布同时提供服务端更新信息和安装包；只发布客户端变化时，也须携带有效的服务端更新信息。Ubuntu 本轮保持原版本和手动安装流程。

## 单窗口远程与 Android 状态修复

- 修复 SYSTEM 服务环境下 Windows Graphics Capture 的 COM 身份问题；窗口枚举与捕获在限定范围内使用登录用户身份，保留服务原有的系统权限和锁屏恢复行为。
- 应用列表接口缺失、捕获能力不可用时显示对应原因。
- Android 手动收起系统键盘后，控制按钮同步恢复为“手机键盘”。
- 修复 Android 启动配置同步后，“点击与滚动”和“滚动模式”的本地状态被清除的问题。

Windows、Android 使用 CNB 和 GitHub 更新。Android 继续沿用原签名，由用户在系统安装界面手动确认。此次不操作 OPPO，也不更新共享目录。
