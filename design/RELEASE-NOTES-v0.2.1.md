# RHRemote v0.2.1

- Windows 和 Android 设备卡片增加上移、下移按钮，设备顺序自动保存。
- WebDAV 同步设备顺序，刷新和重启后保持；离线设备和本机设备也可移动。
- 两端同时调整出不同顺序时提示冲突，由用户选择保留哪一端；合并不会删除另一端新增的设备。
- 所有移动按钮共用 `device.move` 接口，参数为 `uuid` 和 `direction`（`up` / `down`）。

这是开发预览版。Android 使用原有开发签名，Windows 尚无代码签名证书。本次更新没有改变串流引擎，也不代表稳定 30 / 60 FPS 或 4K 验收通过。
