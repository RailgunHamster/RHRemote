# RHRemote 0.2.20

## Windows 多会话

- 支持同时连接不同的远程设备，每台设备使用独立的远程窗口。连接第一台后，设备列表仍可继续选择并连接其他电脑。
- 重复点击同一台设备会切换到已经打开的窗口。设备列表分别显示各台设备的连接、重连与断开状态。
- 每个窗口独立管理串流进程、控制接口、断线重连、声音、悬浮控制条及键盘。断开、关闭其中一台不会结束另一台的连接。
- 配对身份使用每个会话独立的本地快照，避免并行进程写回旧的配对列表。共享配置仍由设备主窗口保存，键盘偏好按实际修改项提交。
- 关闭设备主窗口时等待所有远程窗口完成清理；有远程窗口打开时可检查更新，安装更新须先关闭这些窗口。

## 更新与兼容性

- Windows 安装更新时使用与应用配色一致的独立过渡窗口，显示安装阶段并等待新版主窗口出现。过渡窗在安装目录之外运行，更新程序启动失败时自动撤回。
- 过渡窗只识别本次安装中新启动的主程序，避免把同名串流进程误认作更新完成。支持浅色、深色及当前显示器位置。
- 修正客户端视频窗口的指定显示器选择；副屏测试找不到目标显示器时会报错，不回退主屏。

Windows / Android 正式安装包发布到 CNB 与 GitHub，默认 CNB、GitHub 备用。Android 同步版本号为 0.2.20，versionCode 为 431，沿用原签名；本次没有 Android 功能改动，安装仍由用户在系统界面手动确认。

Ubuntu 客户端／服务端已发布版本仍为 0.2.15。本次不更新 Sunshine 引擎或已部署服务端。
