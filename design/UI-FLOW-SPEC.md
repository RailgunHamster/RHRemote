# RHRemote 客户端交互规范与验收

目标：完整整理 Windows 与 Android 的设备、连接、设置、更新、同步和会话操作流程。视觉沿用已选的 HelpWire D 方向；交互以 HelpWire 的设备列表 → 选中设备 → 连接 / 编辑 → 会话工具栏为主线。Sunshine 的配对协议及 RHRemote 的 WebDAV / 更新功能按相同的表单和状态规则接入，不伪称这些功能来自 HelpWire。

参照：[设备列表](https://kb.helpwire.app/client-management/client-list/)、[编辑资料](https://kb.helpwire.app/client-management/edit-client/)、[添加设备](https://kb.helpwire.app/remote-control/add-client/)、[开始连接](https://kb.helpwire.app/remote-control/install-operator-app/)、[会话菜单](https://kb.helpwire.app/operator-application/operator-menu/)、[连接选项](https://kb.helpwire.app/operator-application/connection-options/)、[断开](https://kb.helpwire.app/remote-control/disconnect-remote-control/)。资料名称编辑的参照行为是编辑后自动保存；复杂连接表单采用明确提交与取消，离开时保护未保存内容。

本规范覆盖最终目标。单项通过不等于整个 UI 目标完成。验收必须同时检查真实控件操作、控制 API 状态和持久配置，布局边界或测试数量不能替代业务流程验证。

## 全局规则

1. 同一时刻每个界面只有一个清晰的主要动作；分类导航、状态开关与提交动作视觉区分。
2. 一个按钮只产生一次动作；等待、失败、取消、清理和可重试状态必须可见。
3. 返回恢复原设备与搜索条件。切换分类不提交、不丢失输入；普通返回不等于悄悄放弃设置。
4. 未保存表单离开时给出保存后继续 / 放弃更改 / 继续编辑。保存失败留在对应字段所在分类。
5. 所有控件和确认选项均经共享动作 API；API 和界面的结果一致。
6. 不以缓存在线状态禁止备用地址连接；配置地址、当前选路和已显示画面是不同证据。
7. 不改变用户的配对、画质、声音、WebDAV 和业务服务来换取“界面测试通过”。布局验证使用模拟器；Windows 使用独立预览配置。

### 连接状态、取消与失败返回（0.2.11-preview.10）

- C1–C3：两端使用独立连接页，显示当前设备与连接阶段。建立连接时只有取消动作；清理中禁用重复取消及重试；明确失败且清理完成后显示“返回设备 / 重试连接”。重试固定针对本次设备，不借用后来选中的其他设备。主动断开、首帧前取消、意外失败及自动恢复分别保留状态。
- Windows 原先附加在任意页面底部的整组会话控制已移除，活动会话控制继续放在远程画面上方。连接页的返回、重试、取消与 Android 控件统一经过动作目录；新增 `connection.retry` / `connection.dismiss`。返回保持设备选择及原搜索；连接中的导航明确要求先取消或断开，防止异步操作抢回其他页面。连接页以外的旧重试 / 关闭动作不能丢弃设置草稿。
- 首帧信号与协议连接分开：Windows 原生报告 `firstFrame` 后，连接页才显示已连接；Android 将视频渲染提交回调接到连接状态，Activity 接管本身不算首帧。该信号表示渲染提交，不能视为显示器扫描输出耗时；Windows 同时保留了解码桌面截图确认实际内容。
- 打包复验继续发现旧会话结束状态的竞争：HTTP 查询先于会话锁，后备状态文件也可能属于前一进程。`preview.10` 在处理失败、首帧与通道释放之前，先将状态的 `processId` 与当前拥有的串流进程核对；未对应时保留等待，由既有超时预算约束。新增真实子进程回归，检查旧错误、旧首帧、旧释放结果和无进程标识的状态都不能结束或接管新连接。原有真实进程清理测试仍检查对应进程标识，不放宽清理条件。`preview.9` 的 Windows 安装包在复验中失败，不能作为通过版本；保留失败记录供对照。
- 实测修复一个状态查询竞争：Windows 一次串流状态读取失败会返回空值，之前可能使等待中状态暂时变为空闲。本轮明确将空值视为“没有新证据”，保留既有连接状态，既不误报失败，也不开放第二次连接。明确的 native 错误、清理和终止结果仍正常处理。取消后的晚到错误不能变成失败提示。
