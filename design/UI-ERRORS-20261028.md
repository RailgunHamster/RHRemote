# 两端错误提示、主题与会话布局

本地 Windows preview.46、Android preview.35（versionCode 259）。未公开发布、未操作 OPPO、未启动新的 Windows 客户端窗口，完整 UI 目标仍未完成。

## 修改与发现

原错误文字在浅深两种主题下均使用深红色。现在 Windows 的表单、更新、连接、复制预览、同步确认框、会话控制与弹出菜单使用同一语义色；Android 页面与会话面板通过 `RhUiStyle` 共享该色。浅色仍为 `#b04452`，深色为 `#f28b9c`。Android 断开按钮保留正常／禁用的颜色状态，不再覆盖成单一固定色。

在深色面板背景 `#1b2232` 上，名义前景／背景颜色对比度由约 2.87 提升为 6.77；在本轮三个深色背景中最低为 5.29。`error-colour-analysis.json` 还检查了十张实际应用绘制图中的实色前景像素。这是颜色测量，不是物理显示器或整套无障碍的认证。

扩展检查发现 Windows 悬浮音量输入仍使用浅色原生控件调色板。控制条与独立弹出菜单现明确跟随应用主题；`windows-headless/toolbar-audio-compact-dark.png` 保留此前浅灰输入框，最终图在 `windows-final`。错误色与音量框的修复均未改变会话参数、按钮动作或输入协议。

Android 面板原滚动条覆盖右侧按钮边框。现在为滚动条和内容留出位置，避免按钮边框被遮挡；修正后单独复验三种尺寸和两种主题。长列表继续滚动，收起开关及断开按钮仍在固定位置。
