# 当前实现与已确认要求

更新：2026-10-22。实现尚在进行，不把已编译、已连接或短测快照当作稳定帧率验收。

- Windows 改用 Rust + Slint。旧 Qt 界面仅保留在 Moonlight 原生串流适配器中，不是新的产品界面。
- Android 保留原生 View + Java；用户认为现有安卓版可以，避免无关的视觉重写。
- 保留 Sunshine 服务器及业务。winserver 测试期间的全局禁音已撤销，客户端提供音频开关；测试仍保持客户端静音。

- 设置使用分类 Tab。配置同步页填写 WebDAV 地址、账号及密码。
- 同步各客户端的配置分组、设备元数据及主题；各端只使用自己的分组，其他端的配置可显式复制。配对证书、私钥、同步密码和接口令牌留在本机。
- 指向本机的设备配置仍保留、显示、可编辑并参与同步；本机识别是运行时判断，不同步 isSelf 标记，不按名称或 IP 删除配置。当前客户端禁止对自己的设备 UUID 发起连接。
- Windows 更新已接入 Velopack，Android 下载 APK 后打开系统安装界面手动确认。GitHub 与 Gitee 已建仓；已获用户授权将仓库、源码及安装包公开，v0.2.0 发布由 publish-release.ps1 执行。
- 只读参考 winserver `D:\git\RHFiles`。已读 UI CSS、更新与 WebDAV 源码，出处和 SHA256 保存在本地 `results/clients-v2/rhfiles-reference-*.json`。这些本机诊断结果不应公开上传。
