# 当前实现与已确认要求

更新：2026-10-22。实现尚在进行，不把已编译、已连接或短测快照当作稳定帧率验收。

- Windows 改用 Rust + Slint。旧 Qt 界面仅保留在 Moonlight 原生串流适配器中，不是新的产品界面。
- Android 保留原生 View + Java；用户认为现有安卓版可以，避免无关的视觉重写。
- 保留 Sunshine 服务器及业务。winserver 测试期间的全局禁音已撤销，客户端提供音频开关；测试仍保持客户端静音。
- 按客户端实例 ID × Sunshine UUID 保存独立连接配置。两台安卓设备也互相隔离；DisplayName 别名、名称、地址和主机左右键状态作为共享设备资料。
- 首页只显示“远程设备”，删除“你的电脑，随时在手边”“选择一台电脑，继续你的工作”“声音关闭”“轻点选择”“长按菜单”等装饰性文案。
- 每个应用按钮必须映射到明确的 action ID，GUI 与 HTTP 接口共用分发器；测试不再抢占鼠标或通过 Windows 屏幕操作。
- 设置使用分类 Tab。配置同步页填写 WebDAV 地址、账号及密码。
- 同步各客户端的配置分组、设备元数据及主题；各端只使用自己的分组，其他端的配置可显式复制。配对证书、私钥、同步密码和接口令牌留在本机。
- 指向本机的设备配置仍保留、显示、可编辑并参与同步；本机识别是运行时判断，不同步 isSelf 标记，不按名称或 IP 删除配置。当前客户端禁止对自己的设备 UUID 发起连接。
- Windows 更新已接入 Velopack，Android 下载 APK 后打开系统安装界面手动确认。GitHub 与 Gitee 已建仓；已获用户授权将仓库、源码及安装包公开，v0.2.0 发布由 publish-release.ps1 执行。
- 只读参考 winserver `D:\git\RHFiles`。已读 UI CSS、更新与 WebDAV 源码，出处和 SHA256 保存在本地 `results/clients-v2/rhfiles-reference-*.json`。这些本机诊断结果不应公开上传。

## 已验证

- Android 开发包 `com.rhremote.client` 已安装到 OPPO OPD2515，与 Moonlight 并存。
- Android 6 项真实设备输入回归通过；实际连接 winserver 后，主副键补偿、长按和拖拽释放已由自有源测试窗口的事件计数验证。
- 原生 Windows 适配器已连接 winserver，D3D11VA 硬件解码在左侧 C3273IUY 副屏。不能将含动态/静态混合区间的累计 FPS 作为稳定性成绩。
- Rust + Slint 已编译并运行，`GET /v1/state` 与 `POST /v1/action` 已工作；首张预览由本程序自身 `Window::take_snapshot` 导出，没有屏幕自动化。
- Rust 接口实测识别 RailgunHamster 为本机，并确认 winserver 已配对。Rust 用例验证设备配置隔离、取消不保存、无活动串流拒绝输入、自身禁止连接及按钮 action 目录覆盖。

## 待完成

两端分类设置、WebDAV 同步和产品按钮接口已接入。设备连接设置共 24 个字段，分画面/音频/输入/高级；设置页 Tab 顺序为更新、配置同步、外观、关于。WebDAV 支持 HTTP / HTTPS，自动同步间隔 5 / 15 / 30 / 60 分钟，默认 5；账号与间隔留在本机。Rust 当前 24 项测试（含配置、HTTP、间隔和统计清理）；Android 20 项仪器测试通过。双端真实 HTTP / 本机 WebDAV 实测 10 项通过，验证 Windows 1080P 与 OPPO 2520×1680 参数隔离、独立并发编辑、复制草稿的保存与取消、别名同步和清空、主机名保留、冲突不覆盖、明确解决冲突、自身配置保留及 API 不回显密码。旧本机配置迁移到自己的分组，旧远端配置保留为复制来源。

Windows 原生输入 API 在上一轮 2520×1680 功能回归连续三轮通过；这不能证明稳定帧率。本轮 1080P 串流复测曾遇到主机连接失败、无解码统计；本机有线与 Wi-Fi 同处 192.168.0.0/24，指定有线源地址可连接目标端口，指定 Wi-Fi 源地址不可达，系统路由未修改。最终复测结果另记本地诊断文件；不以配置同步通过代替串流通过。

两端带音频控制的实际连接及输入回归已通过。逐帧统计已记录 Windows 557 / Android 206 帧且无记录丢失，详见 STATISTICS.md；分析完成删除原始 JSONL，旧报告在下次测试清理。最新整套跨端同步夹具因 Windows 已有用户 WebDAV 配置未运行，保留用户账号，改用隔离 HTTP 读写测试；此前 10 项跨端测试通过不能冒充新增音频隔离和间隔案例已通过。发布过程需逐项验证公开下载、更新清单和包校验；不把生成本地安装包等同于线上更新验收。稳定 1080p30 / 60 / 4K 仍需按原有帧间隔标准单独验收；这次 UI 和同步改造不构成性能通过。
