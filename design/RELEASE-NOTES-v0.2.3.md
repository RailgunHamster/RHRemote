# RHRemote 0.2.3

- 修复 Windows 自动分包被当作命令行 `--packet-size 0` 传递后无法启动串流的问题；参数错误直接返回客户端，避免隐藏错误窗口长时间等待。
- Windows / Android 连接设置新增“网络”：多个设备地址随 WebDAV 同步，自动选择局域网或 Tailscale 地址，也可以手动指定网络类型。
- VPN / 外网自动采用兼容的分包设置，保留手动分包和独立外网码率上限。
- 新增地址、TCP 与鉴权 UDP 分阶段诊断；所有按钮有对应动作接口。
- RHRemote-Sunshine 统一服务增加配对鉴权的网络发现和单次 UDP 探测，安装器提供针对 Tailscale 网卡的连接规则。
- 保留已有配对、声音、画质、别名及设备顺序；Windows 和 Android 均需升级后再同步新网络字段。
- 包含先前已验证的手柄默认关闭、试解码设备复用及静音探测简化。启动耗时优化仍在继续，不承诺秒开。

本版为开发预览。已进行 Windows Tailscale 串流和公网 DERP 独立转发验证；OPPO 蜂窝实机验收待恢复测试。Android APK 仍由用户手动确认安装。

0.2.2 已从稳定发布中撤回，Windows 请使用本修正版。
