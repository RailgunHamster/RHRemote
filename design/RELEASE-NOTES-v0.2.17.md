# RHRemote 0.2.17

## Windows / Android

- 改善悬浮键盘在白色、深色和复杂画面上的可读性：普通按键底色约 69% 透明，文字保持不透明，并增加深色字形描边和黑白双层边框。
- 完整键盘和简化键盘使用相同的对比度处理，选中、按下的按键保留更明显的蓝色反馈。
- Windows 悬浮键盘改为逐像素透明，避免整窗透明度把文字和边框一起淡化；普通设备和设置窗口沿用原显示路径。Backspace 使用文字标签，避免符号字体缺字。
- Android 移除键盘下方的整块底板，按键缝隙露出未覆盖的远程画面。

这版采用固定描边方案，尚未加入采样远程背景后自动切换配色；不会为此读取桌面或远程视频帧。

## 安装与验证

Windows / Android 正式版和更新信息发布到 CNB、GitHub，默认 CNB、GitHub 备用。共享目录仅保留一套支持在线更新的首次安装包，不再逐版复制或保留预览版本。

Windows 可通过应用更新或安装包升级。Android versionCode 为 426，高于 0.2.16 及 0.2.17-preview.1；沿用原签名，下载后由用户在系统界面手动确认安装。

已通过 Windows 控件、隐藏窗口独立透明度和 Android 键盘绘制／操作检查，覆盖明暗、复杂背景和完整／简化布局。尚未进行这次改动的 OPPO 实机及真实 Windows 串流复验，不将控件渲染对照视为实机验收。

Ubuntu 客户端／服务端的已发布版本仍为 0.2.15，本次不更新已部署服务端。
