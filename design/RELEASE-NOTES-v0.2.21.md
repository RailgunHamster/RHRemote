# RHRemote 0.2.21

## Windows 界面与交互优化

- 设备概览页“桌面连接”主卡增加品牌蓝紫渐变顶栏与串流视觉卡片，并将“分辨率／帧率／码率”和“视频编码／声音／屏幕”封装为独立工况概览卡片，层次更清晰。
- 连接建立页升级为带顶部蓝紫导光条的三步状态节点卡（1 检查地址与配对 → 2 建立串流 → 3 显示远程画面），当前进行阶段高亮显示。
- 主机配对页新增专属“SUNSHINE 安全配对码”展示卡片，采用双层内衬容器突出显示配对数字。
- 串流顶部悬浮控制栏增加蓝紫导光顶条与连接状态点，宽屏模式下将“键盘布局”“显示键盘浮钮”“统计开关”整合为紧凑水平三联布局，减少纵向遮挡。

## 更新与发布

Windows / Android 正式安装包发布到 CNB 与 GitHub，默认 CNB、GitHub 备用。Android 同步版本号为 0.2.21，versionCode 为 432，沿用原签名；安装仍由用户在系统界面手动确认。

Ubuntu 客户端／服务端已发布版本仍为 0.2.15。本次不更新 Sunshine 引擎或已部署服务端。
