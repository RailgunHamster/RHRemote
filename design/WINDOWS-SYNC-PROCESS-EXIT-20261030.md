# Windows 同步提交阶段的进程终止与冷启动

Windows 已使用既有 winserver DAV 服务，通过五个服务器提交／本机保存边界的真实子进程终止和冷启动验证。本轮新增代码仅在 `cfg(test)` 中编译，候选版本仍为 preview.110；没有为这些测试重新打包或替换日常 preview.101。

证据目录：`D:\RHRemoteTools\ui-windows-sync-process-review-20261030`，有效样本为 `attempt01`。`real-process-attempt01.log` 记录真实 DAV 用例通过，耗时 68.58 秒；其中约 61 秒是等待本轮自己的遗留写锁自然到期。

## 五个实际中断点

| 中断点 | 终止前的实际状态 | 冷启动结果 | 原进程 → 新进程 |
| --- | --- | --- | --- |
| `after_remote` | 服务器已接受 PUT，独立 GET 核对合并结果；响应被暂留，本机仍为旧配置，`pendingTransfer` 已落盘。 | 显示待确认、暂停自动同步。第一次手动重试得到真实 HTTP 423；等待自己的锁到期后恢复。 | 161268 → 14796 |
| `before_apply` | 客户端已收到成功响应并释放锁，`pendingApply` 已落盘，本机尚未应用。 | 保留待确认和自动同步屏障，手动重试完成。 | 149092 → 70684 |
| `after_shared` | Controller 已保存并回读本机配置，设备恢复动作尚未返回；完成时间和基准仍为旧值。 | 保留待确认和自动同步屏障，手动重试完成。 | 168004 → 180816 |
| `after_apply` | 设备恢复动作已返回，Controller 已更新界面状态；尚未保存同步完成记录。 | 保留待确认和自动同步屏障，手动重试完成。 | 138088 → 128716 |
| `after_account` | 已核对本机配置，完成账户记录也已原子保存；停在完成账户记录的再次回读之前。 | 正确识别为已完成，没有错误暂停；再手动同步仍完成。 | 138536 → 174456 |

最后一行与 Android 的任务日志边界不同：Windows 此时已经保存完整完成状态，没有 Android 那份尚待清除的任务标记。不能为了让两端结果相同而要求 Windows 再显示待确认。

## 界面和恢复证据

测试重新创建 ConfigSync、Controller、MainView 和实际 MainWindow，使用 Slint TestingBackend 软件渲染及实际“立即同步”控件的指针回调。前四轮分别核对自动调度不满足条件、显式自动请求返回 `sync_interrupted`，且转发器没有新增请求；切换设置分类、编辑后取消也不清除中断状态或改写账户文件。

五轮手动恢复后，本机设备别名、主题、合并基准与服务器内容均符合预期。每轮客户端成功 PUT 两次，分别是中断前提交与恢复后的提交；父测试准备文档和所有权标记不计入该数量。`after_remote` 首次重试收到自己的 HTTP 423 后，实际等待 60931 毫秒再手动操作；没有缩短服务端锁，也没有增加产品自动重试循环。

图像是应用自己的软件渲染输出，保留 `cold.png`、`cancelled-draft.png`、`reconciled.png`；第一轮另有 `owned-lease.png`。没有使用系统截图、系统输入注入或 computer use。

## 数据和进程范围

测试使用人工构造的两设备配置，只借用既有账户的凭据标识，在 Rust 同步代码内部读取系统凭据并完成 HTTP 认证；密码未写入参数、环境变量、文件或日志。测试后端拒绝配置和移除账户动作，不创建或删除借用的系统凭据。

每轮新建唯一的 `RHRemote-UI-wincommit-…` 隔离目录，先确认不存在，再写入带随机值的所有权标记。转发器只接受 localhost 和该轮配置文档的指定方法。正常 DAV 文档仅 GET，五轮前后均按原始字节比较一致；正常本机账户文件也逐轮比较一致。

清理前重新核对所有权标记，取得目录独占锁，检查目录成员和文档内容均属于该轮，再删除并确认 404。五个隔离目录全部清理完成，转发器全部退出。父测试只通过最初创建的子进程句柄终止本轮专用进程，没有按名称／PID 终止已有程序。

日常 Windows 的 preferences、配对 INI 和同步账户三个文件哈希保持不变。OPPO、业务服务、显示布局及日常客户端未操作。

## 验收边界

这是实际 Windows 测试可执行文件的进程终止，使用正式 ConfigSync、Controller、本机原子文件写入、系统凭据及真实 DAV 请求；设备恢复后端返回测试设备行，没有启动原生串流引擎。Slint 控件运行于软件测试后端，没有物理 Win32 窗口。因此不替代日常／发布版 RHRemote.exe 的运行验证、原生设备恢复、物理断网、断电持久性或完整 UI 验收；这些范围仍在 TODO。

完整 `cargo test --locked --workspace` 通过：Core 135、Host 23、Relay 1、Transport 13、UI 226 项，零失败；3 项按默认标记忽略，其中本轮新增的父测试和子测试已由显式真实 DAV 运行覆盖，另一项是原有公网更新测试。

最终 `final-audit.json` 的 67 项核对全部通过，包含五个样本、正常配置哈希、日常及候选程序哈希、服务端配对记录和测试进程退出。既有清理工具未发现超出保留范围的产物，删除逻辑字节数与实测释放量均为 0；检查后 D 盘可用 979004739584 字节。
