# Android 控制面板：大字号及完整操作名称

本地 Android preview.109 修正控制面板在 200% 系统字号下的文字裁切，保持现有颜色、分组和共享动作。Windows 日常仍为用户批准安装的 preview.101，后续 Windows 候选为 preview.108；本轮没有更改 Windows 客户端或操作 OPPO。

证据目录：`D:\RHRemoteTools\ui-android-large-font109-review-20261030`。

## 故障与行为

preview.108 的原生 View 在 360×800、200% 字号下复现：“收起”换行后被固定 48 dp 高度裁切，Ctrl+Alt+Delete 的文字不完整。基线 `20261030-font108-baseline01` 的失败断言及 PNG 保留。此前八组浮层检查只覆盖到 130% 字号，不能用它们证明 200% 可用。Android 官方也建议用最大 200% 字号检查应用。[官方说明](https://developer.android.com/about/versions/14/features#non-linear-font-scaling)

现在按实际字体测量文字，不再依靠缩小网格按钮字号来挤进固定列数。空间不足时，设备名与顶部动作分成两排，开关和断开仍位于不滚动的顶部；快捷操作及屏幕操作网格减少列数，正文保留滚动。收起／控制按钮按文字和图标确定宽度，维持同一位置；屏幕列表行允许内容决定高度。悬浮键盘按字体确定最小按键尺寸，保留右下倒 T 与左侧 Tab／Shift+Tab 的相对位置。

默认字号仍保留原有两／三列上限，按键透明度、显示开关、空白穿透和接口不变。没有更改主机显示模式策略、编码、网络、远端按键或声音设置。

## 保留的中间失败

初版调整触发了未初始化 GridLayout 的推导列数与实际子项不一致；现在在首次测量前明确建立格子位置，不再把未测量的推导结果当作已配置状态。[Android GridLayout 源码](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-15.0.0_r1/core/java/android/widget/GridLayout.java)

初版增加面板布局回调造成音量页的测量回归，已撤回该回调，改为直接预算固定部分的高度；保留原音量拖动断言并通过。另一版单行水平滚动使离屏绘制的收起文字消失，改为禁止水平滚动的单行上限，并增加文字像素检查。`native03`／`native04` 的早期文字检查不足，以及构建未完全结束时使用旧测试 APK 的 `pixels06`，均不作为最终新增像素检查的证据；`final07` 明确等待构建成功后核对测试 APK 哈希。

`final10` 的末端可达检查把滚动容器的内容原点当成了可见边界，属于探针坐标错误。已改为 View 的 `getDrawingRect` 再转换到根坐标，包含容器自身滚动量；没有为此修改产品滚动逻辑。`final11` 的浅色 360×800 输入页，scrollY 为 59，统计按钮 `[175,630][324,674]` 完整位于视口 `[26,234][334,674]` 中，且有实际绘制图佐证。

自然 RTSP 缺字节、真实外网、公开更新源及其余 UI 待办继续保留，见 [TODO](../TODO.md)。
