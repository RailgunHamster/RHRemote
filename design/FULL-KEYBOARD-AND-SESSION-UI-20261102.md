# 完整／简化悬浮键盘与 Windows 会话结束页

2026-11-02，客户端测试版本 `0.2.16-preview.2`。Android versionCode 423。

## 使用

- 连接后，右上角的「键盘」浮钮打开悬浮键盘；原位置的「收起」关闭。控制页的「显示键盘浮钮」决定是否显示这个入口，关闭入口后仍可通过控制页打开键盘。
- 完整布局包含标准 104 键与 4 个媒体键，共 108 键。包括 F1–F12、主键区、导航键、方向键和数字小键盘。修饰键可先点选，再点普通键发送组合，组合发送完自动释放。
- 键盘自身及控制页均可切换「完整／简化」。简化布局保留 Esc、Tab、Shift+Tab、Win、Enter、Backspace、Delete、Ctrl、Alt、Shift 和方向键；方向键在右下、Tab 在左侧。极矮窗口保留核心导航按键，完整布局仍可切回使用。
- 简化布局的 Win 单独发送按下／释放，可直接打开开始菜单；完整布局的 Win 可点选用于组合键。
- Android 窄屏保留按键尺寸，可以滚动；「主键区」「导航 / 数字」可快速定位。显示输入法时保留浮钮，切换到悬浮键盘会关闭本次输入法。
- 布局和浮钮可见性属于本端界面偏好，重启或重连后保留，不写入 WebDAV 的共享设备／连接参数。

## Windows 断开界面

「返回设备」使用与其他页面一致的左上返回入口。正常结束／取消后，设备状态旁直接显示「再次连接」；失败显示「重试连接」。连接和清理尚未结束时仍保留取消／清理状态，不能重复启动。

结束后不再显示旧的三段连接进度。控制栏、键盘和菜单在终态隐藏；Windows 原生隐藏过程额外确认窗口属于本进程、解除 owner，并清除 APPWINDOW、设置 TOOLWINDOW。辅助窗不再拒绝所有关闭请求。自动恢复中的会话与已经结束的会话分别处理，恢复期间仍保留必要控制。

## 接口与安全边界

新增共享动作：`stream.keyboard.catalog`、`stream.keyboard.press`、`stream.keyboard.layout.set`、`stream.keyboard.button.set`。Android 另有 `stream.keyboard.reveal` 定位窄屏按键。所有新增按钮使用相同动作分发，不依赖屏幕坐标或操作系统输入注入。

108 键定义共用 `client/shared/keyboard.json`。原生引擎按同一目录验证键和修饰键，不信任调用者直接传入的 VK 数组。Ctrl+Alt+Delete 仍调用既有主机安全注意序列接口；普通组合键完整发送和释放，失败也尝试释放所有已尝试的键。测试统计不记录输入的文字内容。
