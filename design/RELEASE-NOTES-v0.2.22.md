# RHRemote 0.2.22

## 外层键盘、自定义快捷键与自由拖动

- Android 外层屏幕右上角同时提供「手机键盘」与「键盘（悬浮键盘）」两个独立浮钮，无需点进二级菜单即可直接唤起或收起系统输入法。
- Windows 与 Android 的「控制 → 操作」新增「外置快捷键」，可勾选任意常用快捷键固定在屏幕最外层，点击即可立即发送。
- 外层浮钮、外置快捷键与简化悬浮键盘按键均支持按住自由拖动位置（完整版 108 键悬浮键盘保持固定阵列），松手不误触点击，位置与先后层级自动保存在本机。按钮重叠时按拖放先后顺序优先触发最上层按钮；「控制 → 操作」新增「重置位置」一键恢复默认布局。

## Android 本地选项记忆与 Windows 多会话优化

- Android 串流中切换的「点击与滚动」「滚动模式」「触控板／直接点击」「统计开关」「声音开关与音量」以及外置快捷键、按钮拖动位置均实时保存在本机，下次连接时自动恢复生效。
- Windows 连接远程设备时不再弹出多余的伴随状态窗，每个连接仅打开 1 个远程画面窗口；连接阶段进度与「取消连接／断开连接」直接在主界面设备卡片中展示与操作，画面关闭或断开后后台会话进程自动退出。

## 更新与发布

Windows / Android 正式安装包发布到 CNB 与 GitHub，默认 CNB、GitHub 备用。Android 同步版本号为 0.2.22，versionCode 为 433，沿用原签名；安装仍由用户在系统界面手动确认。

Ubuntu 客户端／服务端已发布版本仍为 0.2.15。本次不更新 Sunshine 引擎或已部署服务端。
