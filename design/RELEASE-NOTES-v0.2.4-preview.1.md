# RHRemote Android 0.2.4-preview.1

用于排查 OPPO 外网连接问题的安卓预览版，arm64，沿用现有应用签名。下载 APK 后直接
覆盖安装，保留应用数据和本机配对记录。

- 修复设备列表不检查已保存、同步的 Tailscale 等备用地址。
- 修复主机网络信息中 Tailscale 地址未自动学习、同步的问题。
- 修复应用重启后配对状态暂时为空时误进入配对流程；先用保存的证书确认主机，
  证书不符时停止连接，不降级到明文 HTTP。
- 包含当前开发分支的 HTTPS 内置中继、连接恢复、启动前选屏和原生控制面板改动。

APK 和测试 APK 编译通过，45 项 JVM 测试通过，其中包含真实本地 TLS 的证书校验回归。
OPPO 当前外网连接、媒体、配对取消和网络切换仍待实机验收。此版本不表示这些验收已完成。

此预览版单独发布，不提供稳定更新 feed，不替换 Windows 或 Android 稳定版 0.2.3。
Gitee 的 latest 下载行为尚未按预览发布验收，本预览安装包先提供 GitHub 下载；源码仍
同步 GitHub 和 Gitee。

Android versionCode 为 204；后续稳定版本必须使用至少 205，保证能从此预览版继续更新。
精确源码提交、APK 哈希和签名证书指纹见随包 `build.json` 和 `SHA256SUMS.txt`。
