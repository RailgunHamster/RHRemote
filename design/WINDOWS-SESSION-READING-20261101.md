# Windows 串流错误详情与恢复操作

2026-11-01，本地 Windows 候选 `0.2.11-preview.188`；Android 源码仍为 185。本轮没有替换日常 Windows 101、操作 OPPO 或模拟器，也没有连接真实主机、改配对或重启服务。完整 UI 目标继续进行。

## 原问题与改动

串流操作的“错误详情”和独立“连接失败”卡片，原有正文支持鼠标滚动，却没有能通过 Tab 进入的阅读区域。对同一观察器，旧版八组均不能进入正文或用按键读到最后一行；原有恢复按钮本来就完整可见、可操作，没有把这一点记为新增修复。

- 两处正文共用 `SessionErrorDetails`，内容超过可视高度时才加入 Tab 顺序并显示焦点边框；短错误不增加多余停靠点。
- 支持上／下、PageUp／PageDown、Home／End。Enter 只留在阅读区域，不触发关闭或重试；Escape 保持原有会话导航语义。
- 正文独立滚动，关闭、返回设备和重试保持在固定区域。内容保留 4 逻辑像素内边距，不紧贴焦点边框。
- 重复发布相同错误保留阅读位置，出现新错误从顶部开始。禁止横向滚动并按可视宽度换行。
- 继续使用 `scroll|picker`、`scroll|connection-error` 和原有共享动作，不增加另一套按钮调用路径；保存表单的 `SaveErrorDetails` 没有修改。
