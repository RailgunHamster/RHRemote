# RHRemote 0.2.11-preview.38

Android 会话弹窗统一 Esc 关闭／取消行为，通过已有接口执行。菜单和断开确认的旧回调只对所属弹窗生效，避免误操作后打开的弹窗。

290 项单元测试通过。无窗口模拟器在临时 1080p30／6 Mbps 真实串流中完成浅深主题的 Esc、Enter、旧回调、返回和主动退出复验，原配置已恢复。应用内按键派发不代表真实外接键盘、动态帧率或原 25 Mbps 画质验收。

一次设备查找失败仍未定位。完整 UI 验收继续保留原 25 Mbps 大帧缺失及其余流程。仅本地 ARM64 Release 候选，未安装到 OPPO、未发布；Windows 保持 preview.47。
