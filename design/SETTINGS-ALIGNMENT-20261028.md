# Windows 连接设置对齐（本地 preview.53）

用户指出连接设置贴着上方分隔线、整体不齐。检查自身渲染图和实际布局后确认是排版问题；上轮控件可达／不越界的检查没有覆盖对称留白与同列对齐。

## 原因与修正

- 旧版设备页签栏高 48，按钮高 38，没有垂直内边距，按钮按顶部排列；实际量到上边距 0、下边距 10，选中背景贴着上方边界。现在栏高 56、上下各留 9，按钮高度保持 38。
- 页头固定使用 20／24 的左右边距，分类及表单又使用按可用宽度计算的居中边距；窄屏错开 4，大窗口偏移更多。设备名、概览／连接设置、分类、表单和底栏现在使用同一内容列。概览正文也沿用这条内容列，切换概览与设置不让页头横移。
- 标题行现在明确为 32 高，26 高的状态标记在行内居中；地址行 16 高。两层页签使用相同的高度和留白，分类栏底部的分隔线单独绘制。

操作 ID、设置内容、保存／离开保护及服务端均未改变。Android 本轮没有代码改动，保留现有 preview.52。
