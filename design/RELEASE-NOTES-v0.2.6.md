# RHRemote Android 0.2.6

- 修复自动重连启动新窗口前提前释放通道的问题，保持占用直到新窗口的控制器完成接管。
- 修复初次连接的窗口已开始初始化时取消，通道可能提前释放的问题；下一连接必须等待该窗口实际清理完成。
- 取消重连时通知当前 JNI 和 HTTP 请求；旧响应、迟到窗口和重复回调不能打开旧会话或覆盖新会话。
- 打洞落到中继、主机身份检查失败或部分启动失败时，先关闭临时代理，再尝试下一路径。清理失败会停止选路并提示。
- 窗口接管超时显示明确提示；交接完成后释放对旧窗口的引用。
- 保留 0.2.5 的下载并安装、下载进度、已下载状态保存和安装权限引导。
