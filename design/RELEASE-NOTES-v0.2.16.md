# RHRemote 0.2.16

## Windows / Android

- 增加完整 108 键悬浮键盘，包含功能键、主键区、导航键、方向键、数字小键盘和媒体键，支持点选修饰键发送组合键。
- 支持完整／简化布局切换，并在本端记住选择。简化布局保留方向键、Tab、Shift+Tab、Win、Esc 等常用按键，Win 可单独发送。
- 增加固定位置的键盘浮钮，在同一位置展开和收起；控制页可设置是否显示浮钮。

## Windows

- 断开后可直接再次连接，返回设备移到左上方，与其他页面一致。
- 会话结束后移除旧连接进度；正常结束或失败时清理控制、键盘和菜单辅助窗口的显示状态、owner 与任务栏样式。自动恢复中的会话仍保留恢复控制。
- 调整窄控制栏中快捷操作和键盘偏好项的顺序，保持重试与常用快捷键可达。

## Android

- 修正打开输入法后控制浮标越界，保留输入法占用区域和动画期间的可用操作区。
- 单指滚动与默认双指统一倍率，修正起步死区跳动并过滤侧向抖动，保留细小增量和方向反转。
- 窄屏完整键盘可滚动，并可快速定位主键区、导航和数字区。

## 安装与验证

本次发布 Windows 和 Android 客户端。Windows 可通过应用更新或安装包升级；Android 下载 APK 后由用户在系统界面手动确认安装，原签名和配置沿用。Android versionCode 为 424，高于此前预览版。

Ubuntu 客户端／服务端的已发布版本仍为 0.2.15；本次不替换已部署服务端。

已通过相关控件、输入映射、组合键释放、偏好保存、窗口清理和更新元数据检查。OPPO 实机触屏／输入法手感及原任务栏残留场景仍需实机复验，不将模拟检查视为实机验收。
