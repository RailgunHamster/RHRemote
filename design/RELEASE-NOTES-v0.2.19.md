# RHRemote 0.2.19

## Windows / Android

- 左侧直接显示远程设备列表，添加、刷新入口移到列表标题旁，设置入口固定在列表下方。主题切换统一放在“设置 → 外观”。
- 设备和连接路径使用拖动柄排序，显示插入位置。设备顺序立即保存并参与 WebDAV 同步；连接路径顺序仍通过当前设备设置的保存、取消流程处理。
- 设置分类栏与正文之间保留固定分隔线和留白，滚动内容不会再贴住分类栏。窄窗口中的代理参数自动换行。
- 历史更新记录改为整行展开，版本号与发布时间分列；空间不足时日期显示在下一行。
- 整理设备顺序时保留当前选择与未保存的连接草稿，并保留键盘及 Android 无障碍排序操作。

## Android 悬浮键盘

- 完整 108 键根据可用宽度重新排列主键区、导航区和数字区。竖屏平板采用分区堆叠，窄屏采用换行与纵向滚动，避免横向裁切和过小的按键。
- 保留完整、简化键盘切换、分区定位和快捷浮钮，适配屏幕旋转与系统输入法占用的空间。
- 改善短横屏、大字体下的设置页面，保持正文和保存、返回操作可用。

## 更新与发布

Windows / Android 正式安装包发布到 CNB 与 GitHub，默认 CNB、GitHub 备用。Android versionCode 为 430，高于 0.2.19-preview.1 的 429，沿用原签名；安装仍由用户在系统界面确认。

发布后保留最近 3 个正式版本及最新的有效预览版本，额外保留 Linux 当前使用的 0.2.15。Git 标签、源码历史和共享目录中的首次安装包不受发布附件清理影响。

已通过 Windows 341 项、Android 707 项及核心层 191 项检查，并完成两端控件和离屏绘制验证。本次未进行 OPPO 实机和真实串流验收。Ubuntu 客户端／服务端已发布版本仍为 0.2.15，不更新已部署服务端。
