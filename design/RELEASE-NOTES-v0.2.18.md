# RHRemote 0.2.18

## Windows / Android

- 更新说明按 Markdown 排版，区分标题、列表、粗体、行内代码和代码块，链接可在浏览器打开。
- 更新页下方增加“历史更新记录”，默认收起；展开后显示版本、发布时间，再展开某个版本查看正文。
- 历史记录从 CNB 获取，失败时尝试 GitHub；网络不可用时保留安装包内已有记录，并提供刷新、重试。
- 历史记录独立加载，展开、收起和查看正文不改变当前更新包、下载进度或单一更新主按钮。

## 安装与验证

Windows / Android 沿用现有更新方式和 Android 签名。Android versionCode 为 428，高于此前正式版；下载后仍由用户手动确认系统安装。

已完成两端控件排版、历史记录折叠、来源回退和更新流程回归检查；本次未进行实机串流验收。Ubuntu 已发布客户端／服务端仍为 0.2.15，本次不更新已部署服务端。

后续发布只维护 CNB 与 GitHub，共享目录继续保留已有的首次安装版本。
