# Windows 主题、返回与确认框复验

最终版本：0.2.11-preview.38；Android 保持 preview.30，未操作 OPPO，未发布。

## 修复与原因

- `view.snapshot` 原先复用单一窗口动作槽，也不清空上一张图的成功状态。连续请求可能覆盖尚未处理的截图；调用方也可能把旧工具栏 PNG 当作新的主窗口图。现在截图有独立请求及 ID、目标窗口、排队／生成／完成／失败状态。窗口动作不覆盖它，隐藏窗口明确失败，晚到结果不能覆盖新请求，错误不会改写别页状态。
- 确认框取消后原本恢复最后一个非弹窗控件。实际点击侧栏先把记录改成侧栏自身，导致“继续编辑”／Esc 与业务 API 发起离开时表现不同。现在侧栏及“返回设备”不替换表单的编辑焦点记录；取消离开恢复原编辑控件，草稿不变。
- 设置保留本次运行中上次选择的分类；分类顺序为更新、配置同步、外观、关于。初版验收脚本误以为每次打开都重置到更新，已修正脚本，未据此修改产品行为。
