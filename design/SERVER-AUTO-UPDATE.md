# RHRemote-Sunshine 自动更新

本轮交付范围为 Windows 服务端，并给 RailgunHamster、winserver、claw 安装和启用。原有服务、配置、配对和业务服务保留。Ubuntu 更新包保持现有独立发布流程。

## 更新来源与可信发布

默认先请求 CNB，失败尝试 GitHub。每个正式版本携带 Windows 服务端包、服务端更新清单和独立签名；客户端版本更新但服务端代码未改变时，可沿用上一份服务端包。签名公钥随服务端源码分发，签名私钥仅由 winserver 的发布账户通过 DPAPI 保存，不进入 Git 或安装包。

清单包含服务端版本、发布标签、包文件名、长度、SHA-256 与源提交。下载前验证清单签名，下载后验证整个包，解包后验证包内文件。拒绝降级、预发布目标、跨目录路径、链接、重复文件和过量解压。

## 安装与恢复

检查和下载不阻塞串流主线程。服务端确认没有串流或待处理连接后，进入更新保持状态，阻止新连接和恢复请求进入；安装前再次确认空闲。

更新工作进程位于安装目录以外，负责备份、更换引擎和服务文件、重启及健康检查。失败时还原文件并重新启动旧服务。配置、配对、证书和用户自定义内容不属于更新包。保留当前包和前一个成功版本的恢复材料，并给进行中的事务留存完整记录。

自动更新设置和状态放在仅 SYSTEM／管理员可写的服务数据目录。更新来源固定为项目的 CNB 和 GitHub，不接受清单提供的任意下载地址。检查、配置和安装操作都有明确接口及状态。
