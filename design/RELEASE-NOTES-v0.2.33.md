# RHRemote 0.2.33

## Windows

- 修复双向剪贴板同步中 64 位随机 `epoch` 经双精度浮点截断导致的长轮询失效、事件无限重放与无上限并发上传线程风暴，彻底消除串流时内核态 CPU 飙升、线程/句柄激增及桌面卡顿问题。
- 修复剪贴板长轮询空闲超时短于服务端等待时长的问题，并补齐工作线程上限、并发回收、渲染/格式事件去重与异常退避保护，同时兼容旧版服务端完整 64 位 `epoch`。
- 同步发布 RHRemote-Sunshine 0.2.29 服务端，将服务端 `epoch` 收敛至 IEEE-754 精确整数范围（兼容旧客户端），并在渲染完成、取消、失败或超时后立即清理事件队列中的陈旧渲染请求。

Android 随本次发布更新版本号。macOS 更新源继续提供 0.2.28。
