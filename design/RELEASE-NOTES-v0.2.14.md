RHRemote 0.2.14

- 设置新增“代理”页：开关、HTTP/HTTPS 下拉选项、地址和端口；默认关闭，协议 HTTP，地址 127.0.0.1，端口 7890。
- 更新、配置同步、远程连接分别选择是否走代理。远程代理通过 RHRemote 中继传输控制、视频和输入，避免 HTTP 代理无法转发原生 UDP 的问题；需已保存的中继身份。代理失败会报告错误，不回退直连。
- 代理仅保存在本机，不写入 WebDAV 同步配置。连接、同步、更新进行中禁止修改生效配置。
- 更新默认 CNB 优先、GitHub 备用；保留首选更新源选择和单个更新主按钮。
- Windows 与 Android 的更新页显示更新日志；发布时把同一个发布时间写入两端的更新信息和发布日志，显示为 UTC+08:00。
- Android versionCode 420，沿用原签名；Windows 采用优化构建。服务端及 Windows Moonlight 引擎沿用 0.2.11，本次无需替换服务。
- Linux 尚未完成实机串流验收，不包含在此发布中。
