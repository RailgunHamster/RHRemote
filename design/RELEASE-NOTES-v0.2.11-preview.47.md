# Windows 0.2.11-preview.47

修复连接设置切换分类后继承旧滚动位置、首屏输入框被裁出可见区域的问题。切分类回到顶部；同分类编辑和刷新继续保留滚动位置与未保存输入。

将正式控制器和状态绑定接入无窗口实际控件测试，验证保存失败、返回确认、配置复制、取消和同步编辑的衔接。核心 112／UI 138 项默认并行通过。

仅本地预览，未发布或安装。Android 无改动，实体窗口和完整 UI 验收仍未完成。[证据与范围](UI-CONTROLLER-FLOWS-20261028.md)

## Android 0.2.11-preview.47

会话“控制 → 操作”新增“滚动模式”开关。开启后轻点发送鼠标中键，四向滑动滚动页面；关闭后恢复原触控方式。中键不受交换左右键影响，双指缩放保留。开关每次会话默认关闭，支持同一套动作接口。

此 Android 预览还包含正在整理的设置卡片、浅深色外观和分组控制面板视觉改动。新增手势和开关联动的 13 项单元测试、模拟器上的 10 项原生触控测试通过；不代表全部 UI、OPPO 实机或外网串流已验收。APK 仅在本地生成，未公开发布。
