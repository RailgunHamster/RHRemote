## 控件和恢复

- 操作／屏幕／声音各分类实际切换并导出自身绘制图；快捷菜单中的项目可见，应用内 Escape 关闭且连接保留。
- 顶部悬浮键盘开关显示十个实际按键，再通过现有开关关闭。方向键保留右下布局，Tab／Shift+Tab 位于左侧；未点击远端键，不计作远端接收回执通过。
- 自有原生窗口以不激活方式最小化／恢复，浮层相应隐藏／重显，首帧状态保持。
- 每轮对自己的会话注入一次中断，观察恢复阶段、实际替换子进程和后继首帧；第二次中断点击真实取消按钮，等原生工作退休后再观察 1.8 秒，确认未重新启动。

后两项不是系统物理输入或物理断网。十二张图来自控制层自身绘制；悬浮按键 PNG 不包含 Win32 窗口级透明混合，不能凭这张图断言桌面实际透明度。
