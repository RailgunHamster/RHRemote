# 双端界面效果整理（本地 preview.50）

本轮先整理完整界面效果及预览，再继续剩余业务流程验收。沿用已选 HelpWire D 方向、RHVideo 配色，Windows 使用 Slint，Android 使用原生 View / Java。完整目标及尚未通过的流程仍见 [交互规范](UI-FLOW-SPEC.md) 和 [TODO](../TODO.md)。

## 界面变化

- 设置正文使用统一卡片、边线、圆角和间距，页头、分类和提交栏保持固定；连接参数按实际可用宽度排列，Android 平板竖屏也可使用标签在左、输入在右的布局。
- 两端外观页显示浅色、深色的实际配色缩略图及选中状态，关于页分为品牌、开源组件、诊断三组，更新页保留单一主按钮。Windows 关于页使用真实标签／值列对齐。
- 会话面板采用一致的线条图标与分组按钮；收起开关位置固定。Android 六个主要操作排列成两列或三列，缩放、统计及滚动模式分组放置，长快捷键标题根据可用宽度适当缩小，不从单词中间折开或裁掉末尾。
- Android 的分类页签改为单行横向滚动，选中的分类自动滚到可见区域，大字体不再把“关于”或“高级”挤到第二行。分类仍调用原来的共享动作，不改变保存／取消语义。
- Android 去掉普通按钮及滚动容器的系统默认焦点灰底，按钮保留应用自己的焦点边线。滚动容器继续保留键盘焦点和滚动能力。

灰底有具体前后证据：`android-focus49-before01/catalog.json` 记录浅深两页的实际焦点均为 `android.widget.ScrollView`，`defaultHighlight=true`，自身 Canvas 图中正文蒙灰。新版只关闭这个系统绘制状态，不删除焦点或滚动。最终图及焦点元数据单独保存，旧图不作为最终效果。

## 可重复生成

- Windows 当前窗口：`tools/Export-RHRemoteVisualCatalog.ps1`，必须指定隔离数据目录和独立端口。
- Windows 无窗口布局：`cargo run --locked -p rhremote-ui --example render_visual_catalog -- <全新目录>`。
- Android：专用 `emulator-5580` 上运行 `RhVisualCatalogDeviceTest`，显式指定新的 `visualRun`；它不发起连接、更新或同步。`visualScene=profile-advanced` 可仅导出焦点绘制对照。
- 离线画廊：`tools/build-ui-visual-gallery.py` 汇总当前目录，支持按平台、分类、主题及尺寸筛选、放大和左右切图；每张图保留来源哈希，并标明布局场景。概览并排比较两端的设备、画面设置、外观及会话面板。

本轮没有把布局导出写成业务测试通过。上轮滚动模式的输入验证单独见 preview.47 的记录；当前尚未完成安装／升级、其余真实会话、WebDAV、外网及 OPPO 实机验收。两端安装包仅本地预览，未发布到 GitHub / Gitee。Sunshine、业务服务及用户声音、配对和画质配置未改动。
