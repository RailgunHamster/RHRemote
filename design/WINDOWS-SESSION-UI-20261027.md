# Windows 会话界面与接口复验

版本：0.2.11-preview.36。Android 保持 preview.30。本轮只生成本地包，未发布。

## 修复

- HTTP 会话控制请求原本在接收循环内同步执行。原生音量、屏幕等控制较慢时，后续状态查询、分类和断开请求也要等待。现在使用独立且最多一个待处理请求的任务，沿用控制器的会话归属检查；断开后的晚到结果不能修改新状态。
- 原生视频窗口出现而尚未收到首帧时，收起的工具栏之前只有“控制”入口。现在保留设备、当前阶段和取消按钮；清理期间禁用重复取消。用户展开控制面板的选择不被连接状态改写，收起／展开开关的位置保持一致。
- 控制面板的 Esc 先收起面板；已收起且等待连接时执行取消；已连接且收起时不发送远程 Esc。按键重复不再次触发动作。选择菜单的 Esc 关闭菜单，并记录同一业务动作。
- 选择菜单的父 FocusScope 不再成为不可见的 Tab 停留点。仍接收子控件未处理的 Esc；不可用菜单项保持禁用。

## 验证

证据目录：`D:\RHRemoteTools\ui-session-api-review-20261027`。

- 修复前真实回环 HTTP 回归因状态请求超时失败；修复后通过。等待控制期间可查询状态、切分类和断开；第二个控制被拒绝，晚到结果被忽略。
- 控制栏 Esc 和菜单 Tab 的真实 Slint 控件回归先复现失败，再修复通过。新增等待卡片在 560×116、355×160 逻辑尺寸下检查阶段与取消按钮完整可见，取消中不接受按钮或 Esc 的重复动作；放置计算覆盖 1、1.5、2.25 倍 DPI 与负坐标屏幕。
- 最终核心 101、UI 119 项测试通过，共 220 项。日志 `rust-ui36-final.log`。
- preview.35 经实际配对按钮建立独立的测试授权，连接、取得解码 PNG 后断开。preview.36 使用同一隔离数据目录重启，保留配对身份和三台原有设备；实际连接按钮再次取得首帧。`connect36-phases.json` 在首帧前记录 `pending=true`、`bodyVisible=true`，2.25 倍 DPI 下工具栏为 1260×261 物理像素。
- `windows36-session-result.json`：166 次应用内控件请求通过。五个工具栏／选择菜单上下文、55 个上下文中的可用控件完成双向 Tab 遍历；顺序互为逆序，没有不可见停留点。菜单 Esc 只关闭菜单，工具栏 Esc 只收起面板，开关位置保持一致。
- 实际按钮覆盖三组分类、只读屏幕刷新、菜单开关、统计开关与断开；实际音量编辑器将 100 调为 99 后恢复 100，音频播放始终关闭。没有执行远程快捷键、屏幕切换或窗口移屏。
- `windows36-input-controls.png`、`windows36-shortcuts.png`、`windows36-displays.png`、`windows36-muted-audio.png` 来自应用自己的渲染器，已检查布局和裁切。未使用 computer use 或系统输入；原生串流测试同时设置 `RHREMOTE_BENCHMARK_NO_INPUT=1`。
- 会话结束后 `streaming=false`、`connecting=false`、`nativeCleanupPending=false`。移除本轮唯一测试授权后，winserver 恢复原有八个授权，授权文件 SHA-256 与基线完全一致。日常及隔离配置 SHA-256 均保持 `030B64999823FEBB5FA55271883B454A05867F4AAA57264739BB06236F7F8092`。

## 边界

首帧由控件请求计时器轮询观察为 2661 ms，另取得解码画面；它不是物理呈现计时，也不证明启动性能改善。等待卡片取消的布局和事件已在真实 Slint 控件回归覆盖，本轮网络连接很快，尚未通过该卡片的实际按钮取消真实首帧等待。

本轮不证明远程安全注意序列、快捷键实际送达、显示器切换、窗口移屏、声音播放、Android 触控缩放或 Windows UIA／系统按键路由。上述任务及完整 UI 目标继续保留，不用本轮测试数量代替整体验收。Sunshine 引擎、服务及业务程序未修改。
